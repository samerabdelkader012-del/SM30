# مصاريف المركبة

تطبيق ويب (PWA) لتسجيل مصاريف المركبة ودخلها، مع عداد GPS وحد يومي وصيانة بالكم.

## النشر على GitHub Pages
1. أنشئ مستودع جديد (Repository) على GitHub، مثلًا `scooter-app`.
2. ارفع كل الملفات الموجودة في هذا المجلد (index.html و manifest.json و sw.js و icon-192.png و icon-512.png و logo.png) في جذر المستودع.
3. من Settings ثم Pages: اختر Branch = main و Folder = / (root) ثم Save.
4. بعد دقيقة يظهر الرابط: https://USERNAME.github.io/scooter-app/

## تثبيته كتطبيق
- أندرويد (Chrome): افتح الرابط، ثم القائمة ثم "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
- آيفون (Safari): زر المشاركة ثم "إضافة إلى الشاشة الرئيسية".

## ملاحظات
- البيانات محفوظة على الجهاز نفسه (localStorage). استخدم زر "نسخ البيانات" في تبويب الشهر لعمل نسخة احتياطية.
- الـ GPS يعمل والشاشة مفتوحة. التتبع في الخلفية يحتاج نسخة أندرويد (Capacitor).
